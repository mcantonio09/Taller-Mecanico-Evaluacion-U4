# Depuración con PDB - Taller Mecánico

## Descripción
Ejemplo práctico de uso del depurador interactivo de Python (`pdb`) para la inspección de variables y control de flujo en puntos críticos del sistema.

## Comandos Utilizados
- **`p [variable]`**: Imprime el valor actual de una variable en tiempo de ejecución (ej. `p costo_prueba`).
- **`n` (Next):** Ejecuta la siguiente línea de código de forma secuencial sin entrar en funciones.
- **`s` (Step):** Permite sumergirse y entrar paso a paso dentro de los métodos llamados.
- **`c` (Continue):** Reanuda la ejecución normal del programa hasta el siguiente punto de interrupción.

## Instrucciones de Ejecución
python debugging/debug_servicio.py
