# Pruebas Unitarias - Taller Mecánico

## Descripción
Este módulo contiene las pruebas unitarias diseñadas con **pytest**, aplicando el patrón **AAA (Arrange, Act, Assert)** y los principios **F.I.R.S.T.** (pruebas rápidas, aisladas y repetibles utilizando mocks para evitar dependencias de la base de datos real).

## Ejecución de Pruebas
Para ejecutar las pruebas en modo detallado (verbose), abre la terminal en la raíz del proyecto y ejecuta:

pytest tests/ -v
